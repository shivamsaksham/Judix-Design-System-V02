# Number Badge

```tsx
import { NumberBadge } from "@/components/ui/number_badges";

<NumberBadge variant="primary" size="s" shape="rounded">7</NumberBadge>
```

### Notes
- Variants: `primary`, `neutral`; sizes: `md`, `s`, `xs`.
- Shapes: `sharp` (default) or `rounded`.
- Works as a simple `<span>`; pass additional props like `aria-label` for accessibility.
